# Projeto Postagens CRUD 2026

Sistema de gerenciamento de postagens com operações **CRUD** (Create, Read, Update, Delete), cadastro e autenticação de usuários. Projeto desenvolvido para estudo e prática de desenvolvimento web com PHP, MySQL, HTML e CSS.

> ⚠️ **Status do projeto: em desenvolvimento.**
> Este projeto **não está totalmente completo**. Algumas funcionalidades ainda estão sendo implementadas como a de cadastrar postagem.

---

## 📋 Sobre o projeto

O **Projeto Postagens CRUD 2026** tem como objetivo praticar a construção de um sistema web com back-end em PHP e banco de dados MySQL, incluindo:

- Cadastro, listagem, edição e exclusão de usuários;
- Sistema de login e logout;
- Página de perfil;
- Módulo inicial de postagens;
- Integrações experimentais e páginas de teste.

O repositório representa uma versão parcial do sistema, que continuará evoluindo com novas funcionalidades e melhorias.

---

## 🚀 Tecnologias utilizadas

- **PHP**
- **MySQL**
- **HTML5**
